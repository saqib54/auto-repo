Connect To GitHub in 3 Steps

  1. 1
    Create GitHub Repository

    Create a public repository named daily-contributions on your GitHub account.

  2. 2
    Push Code & Enable Write Access

    Push this folder to GitHub. Go to Repo Settings > Actions > General > Workflow permissions and set to "Read and write permissions".

  3. 3
    Sit Back & Watch Your Grid Turn Green!

    GitHub Actions automatically runs every day at 09:00 UTC and updates your streak!
